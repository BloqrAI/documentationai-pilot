## Contributing

If you encounter a new failure mode not covered by an existing article, please open an issue tagged `troubleshooting` and `documentation` in `bloqr-systems/bloqr-compiler`. Include:

- The symptom observed
- Any diagnostic output (curl responses, wrangler tail logs, etc.)
- The root cause if identified
- The fix applied

New KB articles should be named `KB-NNN-short-description.md` and added to the table above.
